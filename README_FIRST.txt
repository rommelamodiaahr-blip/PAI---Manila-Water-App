PAI Manila Water Tenant Sharing — V1.2 REVIEW ONLY

Open manila_water_app_V1_2_preview.html in Chrome or use index.html. The full ZIP has PWA assets but has NOT been deployed.

Picture: Bill & Sharing > Take photo / Upload picture. Images are compressed and stored with app records. Optional OCR requires internet and must be manually verified.
Manual input: payment due, billing dates from/to, official consumption, total bill, current charges, and prior unpaid.
Properties: Settings > add/edit/delete properties, CAN and registered water account payer name.
Tenants: add/edit/delete the renter, unit, and submeter.
FULL BACKUP: Settings > FULL Backup JSON. Photos, properties, tenants, bills, meter readings, payments, and drafts are included. FULL RESTORE default REPLACE, or MERGE. For full backup safety, perform a download regularly and keep copies outside the browser.
Storage: IndexedDB in supported browsers, falls back to localStorage. Opening the same HTML using different browsers or file path origins can create separate storage; use FULL BACKUP/RESTORE to transfer records.
Data was not uploaded to GitHub, Netlify, or any server.
